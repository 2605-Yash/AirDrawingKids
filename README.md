# 🎨 AI Powered Adaptive Air Drawing Learning System for Children

An interactive AI-based educational project that enables children to draw shapes in the air using only finger gestures in front of a webcam.  
This system combines **Computer Vision, Hand Tracking, Gesture Recognition, and Adaptive Learning** to create a touch-free and engaging drawing experience.

---

## 📌 Project Overview

Traditional learning methods can sometimes feel less engaging for young children.  
This project introduces a **smart air drawing platform** where children can draw alphabets, numbers, and shapes in the air without touching any screen.

Using real-time webcam input, the system tracks the child's hand movements and converts finger gestures into virtual drawings.  
The platform also provides adaptive feedback, making learning more interactive, fun, and hygienic.

---

## 🚀 Key Features

✅ Real-time hand tracking using AI hand landmark detection

---

## 🏗️ System Architecture

1. Webcam captures real-time video feed.
2. MediaPipe detects hand landmarks.
3. CVZone identifies finger positions.
4. Index finger tip coordinates are tracked.
5. Motion path is converted into drawing strokes.
6. Shapes are displayed on virtual canvas.
7. Adaptive response provides learning interaction.

## ⚙️ Installation Guide

### Step 1: Clone Repository

```bash
git clone https://github.com/2605-Yash/AirDrawingKids.git
cd AirDrawingKids
```

### Step 2: Install Required Libraries

```bash
pip install opencv-python mediapipe cvzone pygame numpy
```

### Step 3: Run the Project

```bash
python air_drawing_kids_premium_v6_final.py
```

> Make sure your webcam is connected and enabled.

---

## ▶️ How It Works

- Start the webcam.
- Place your hand in front of the camera.
- Raise your index finger.
- Move finger in air to draw.
- The system tracks movement and displays it on screen.
- Children can practice shapes, alphabets, and patterns interactively.
